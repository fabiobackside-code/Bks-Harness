06 · CONCEITOS

Seis ideias sustentam o harness

Dois cérebros

Conhecimento (o que você sabe) separado de trabalho (como você trabalha). Dado de projeto nunca vive no cérebro.

Spec é a fonte de verdade

FEAT e TEST aprovados por você, e as tasks decompostas a partir deles, antes de qualquer linha de código.

LOOP-4

No máximo quatro tentativas com objetivo verificável. Depois, o agente para e pergunta.

Gate

Verificação que o harness executa: build, testes e regras de arquitetura. Não é opinião do modelo.

Modelo por papel

Cada agente declara o rótulo do modelo; o lançador escolhe o provedor que responde por ele.

Trava

Segredo, reset --hard fora da task e escrita fora do projeto são recusados pelo hook, não lembrados pelo modelo.
