08 · ARQUITETURA

O harness é um plugin: guias, execução e sensores

MODELO

O provedor

Anthropic, DeepSeek ou OpenRouter, trocados pelo lançador bkhar. Os agentes declaram só o rótulo.

HARNESS DA FERRAMENTA

O Claude Code

O laço de execução, as ferramentas, as permissões e os hooks. O /bkhar:loop é o único executor.

HARNESS DO USUÁRIO

O plugin bkhar

19 skills, 25 comandos, 6 agentes e o Gerente, 8 guardas, scripts, perfis e templates.

Trocar o provedor muda só a camada de cima. Trocar o executor é a portabilidade da 4.0.0, proposta.
