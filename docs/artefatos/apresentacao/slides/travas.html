TRAVA

Quatro e para

RETOMADA

--resume

Depois do bloqueio, com o que mudou; depois da queda, do último ponto seguro, sem contar a tentativa.

O git reset --hard só passa em task/* e wave/*: na branch de trabalho, o secret_guard recusa. A integração é merge --no-ff, e a ordem spec → red → review fica no histórico.
